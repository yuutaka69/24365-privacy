プライバシーポリシー

制定日: 2026年10月19日

24365 v2（以下「本アプリ」）は、運営者本人の個人利用を目的とした Android アプリです。本ポリシーでは、本アプリが音声と Google アカウントのデータをどのように扱うかを説明します。

1. 取り扱う情報

  • 利用者が本アプリに共有する音声ファイル。
  • 音声から生成される文字起こし、要約、処理状況。
  • Google Drive への保存やメール送信に必要なファイル識別情報、処理記録。
  • Google OAuth 認証に必要な認証情報。更新トークンはアプリのサーバー側シークレットとして保管し、Android 端末や公開ページには保存しません。

2. Google データへのアクセスと利用

本アプリは Google OAuth を使い、Google Drive に文字起こし・要約を保存し、Gmail から指定された宛先へ処理結果を送信します。認証画面では Drive の広い範囲に対する権限が表示される場合がありますが、アプリの処理は設定された保存先フォルダと、本アプリが作成したファイルに限って行います。Gmail は送信のみに使用し、受信トレイの読み取りやメールの削除は行いません。

Google から取得したデータは、上記機能を提供する目的だけに使用し、広告、販売、第三者への独自提供には使用しません。Google API のデータは Google Drive と Gmail の各アカウントにも保存され、それぞれのサービス上の設定・保持期間に従います。

3. 音声・文字起こし・要約の処理

音声は Cloudflare のサーバーで一時保管され、OpenAI API を使った文字起こしと要約のために送信されます。処理に必要な範囲で、音声、文字起こし、要約が各サービス事業者に送られます。OpenAI API に送信されたデータの取扱いは OpenAI API のデータ管理についてをご確認ください。

音声ファイルは処理と配送がすべて成功した後に削除します。処理が失敗した場合、再試行のため一時保管されることがありますが、Cloudflare のライフサイクル設定により最長7日で削除されます。

文字起こし、要約、配送データは再試行・処理確認のため Cloudflare のサーバー側にも保存されます。現行設定ではこれらの成果物と処理記録に自動削除期限を設けていません。削除を希望する場合は、下記の連絡先へお知らせください。Google Drive や Gmail に配信済みのコピーは、それぞれの Google アカウント上で削除してください。

4. 外部サービス

本アプリの運用では、機能提供に必要な範囲で次のサービスを利用します。各事業者による情報の取扱いは、各社のポリシーに従います。

  • Google Drive / Gmail: 保存・メール送信 (Google プライバシーポリシー)
  • OpenAI API: 音声の文字起こし・要約 (OpenAI プライバシーポリシー)
  • Cloudflare: アプリのサーバーと一時・成果物データの保管 (Cloudflare プライバシーポリシー)
  • GitHub Pages: 本ポリシーとアプリ紹介ページの公開 (GitHub プライバシーに関する声明)

5. 安全管理と第三者提供

OAuth 認証情報や API キーはサーバー側のシークレットとして保管し、公開リポジトリや本ページに掲載しません。運営者は、法令に基づく場合を除き、処理を委託する上記サービス事業者以外に個人データを提供しません。

6. 利用者と録音対象者へのお願い

録音には会話参加者の個人情報が含まれることがあります。利用者は、録音・共有・処理を行う前に、必要な同意や権限を確認してください。本アプリは、第三者へ配布する録音サービスとして設計されていません。

7. ポリシーの変更

本アプリの機能やデータの取扱いを変更した場合、本ページを更新します。重要な変更は、ページ上に記載する改定日でお知らせします。

8. お問い合わせ・削除依頼

データの取扱いに関する質問や削除依頼は、Google OAuth の同意画面に表示されるサポートメールからご連絡ください。
